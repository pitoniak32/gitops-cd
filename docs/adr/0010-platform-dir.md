# Platform code under `platform/`

Everything only the platform team edits lives in `platform/`: renderer (`render/`), CUE module (`cue.mod/`), `bootstrap/`, `infrastructure/`, `cluster/`, `mise-tasks/`. App teams see `capabilities/` at the root, plus a single `platform/` that they can ignore. One CODEOWNERS line (`/platform/`) covers all of it. This replaces the top-level layout from ADR 0008, and "platform" still means the platform team.

Mise finds tasks through `[task_config] includes` in `.mise.toml`. Tasks still run from the repo root.

## Considered Options

- **`rendered/` into `platform/`**: rejected. It is generated by CI and edited by nobody. Moving it would change the Argo CD bootstrap paths and the Kargo paths on the `env/*` branches that are already pushed.
- **`teams/` into `platform/`**: rejected for now. It is a registry teams read next to `capabilities/`, and it is still platform-owned through CODEOWNERS.
- **`docs/` into `platform/`**: rejected. The ADRs, glossary and gotchas are read by both audiences.
