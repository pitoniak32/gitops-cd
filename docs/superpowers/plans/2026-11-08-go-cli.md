# Go CLI (`gcd`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the bash cluster-setup mise tasks with one Go CLI `gcd`, same behavior, run through `mise run <task>`.

**Architecture:** Go module `platform/cli` (cobra). kind Go package for clusters, Helm v4 SDK for the Argo CD bootstrap, client-go (typed core + dynamic/unstructured for Argo CD and Kargo CRDs). Subprocesses only for docker, mkcert, fnox, cue, gh, open. mise task `cli` builds `.bin/gcd`; every setup task becomes a one-liner.

**Tech Stack:** Go 1.27.2, cobra v1.10.2, golang.org/x/sync v0.24.0 (errgroup), sigs.k8s.io/kind v0.31.0, helm.sh/helm/v4 v4.1.4, k8s.io/client-go v0.35.1 (whatever helm v4.1.4 resolves; keep k8s.io/* aligned).

**Spec:** `docs/superpowers/specs/2026-11-08-go-cli-design.md`

## Global Constraints

- VCS jj: commit with `jj describe -m "<msg>" && jj new`. No git mutations, no push.
- Behavior, order, names, timeouts identical to the current bash tasks (read each before porting): contexts `kind-kargo-demo`, `kind-region-<r>`; Application names; WaitApp = exists (600s) → refresh annotation `argocd.argoproj.io/refresh=normal` cleared → Synced (600s) → Healthy (600s).
- Every command idempotent (re-run = no-op apart from waits).
- KUBECONFIG from env (mise sets `.kubeconfig`). Repo root = `MISE_PROJECT_ROOT`, else walk up to `.mise.toml`.
- Logs: parallel units prefix each line `[hub] ` / `[region-<r>] `.
- Errors: wrap with `fmt.Errorf("<step>: %w", err)`; exit non-zero; no panics.
- Unit tests touch no cluster and no network (fakes, temp dirs).
- Out of scope: renderer scripts, `platform/appsets/check.sh`, `k9s` task.

## Review Focus

- Partial failure in parallel region bootstrap must cancel and fail `infra` (no silent half-up). Pinned by errgroup test in Task 6.
- Re-running `infra`/`up` on a live cluster must not reinstall or restart things (helm install only when release missing; token restart only on change). Pinned by unit tests in Tasks 3 and 5 + e2e re-run in Task 8.
- Secrets from fnox must never be logged. Pinned by test in Task 4 (creds output contains no key material).
- `kargo-restore` must skip, never misrepresent: same skip reasons as bash. Pinned by ported cases in Task 5.
- `regions` output byte-identical to today (CI drift check depends on it). Pinned in Task 2.
