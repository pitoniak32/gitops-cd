# App-team docs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** App-team docs in `docs/guide/` with a generated field reference in `docs/reference/` and every guide YAML example linted, all via one command `gcd docs`.

**Architecture:** `system.SchemaMarkdown` renders `Schemas()` (+ fixture examples) to one markdown page per kind. New package `internal/docs` extracts annotated yaml fences from `docs/guide/*.md`, overlays each on a temp copy of the fixture root, runs `lint.All`, and maps diags back to markdown lines. `gcd docs` = write reference + check guides. Go tests (golden drift + guide check) run in `cli.yaml`.

**Tech Stack:** Go 1.27 (`os.CopyFS`), cobra, existing `system`/`lint` packages. Docs: GitHub markdown + mermaid.

**Spec:** `docs/superpowers/specs/2026-11-12-app-team-docs-design.md`

## Global Constraints

- VCS is jj: `jj describe -m … && jj new` per task; no git mutations, no push.
- Concise commit messages; end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- `gcd lint` and `lint.Changed` are not modified. `config.yaml` is not modified.
- Generated pages start with `<!-- generated by gcd docs; do not edit -->`.
- Fence attributes: `path=<repo-relative>`, `expect="<substring>"`, `fragment`. Unannotated `yaml` block message: `yaml block needs path=…, expect=… or fragment`. Expect mismatch: `expected lint error containing "<s>", got: …`.
- Guide examples use fixture names (`payments`, `search`, fixture targets/teams/stages).
- Guide style: one "you want to…" opening line; link `../reference/<kind>.md` instead of listing fields; link ADRs instead of restating rationale; ~80–200 lines per page.
- After `platform/cli` changes: `mise run cli` to rebuild `.bin/gcd`.
- Test gate: `mise run test` green.

## Review Focus

1. A guide snippet whose lint error lands in a *different* file than `path` (cross-file rule, e.g. stage references unknown target) → diag still reported, at the fence line, message prefixed with that file. Test in Task 2.
2. A diag from the snippet file with line 0/1 (missing required field → `nearest` = document) → mapped to first snippet line, not the fence line or line 0. Test in Task 2.
3. A snippet `path` outside `systems/` / `teams/` or with `..` → reported as a diag on the fence, never written outside the temp dir. Test in Task 2.
4. `docs/guide/` missing (fresh checkout, `--root` sandbox) → `Check` returns no diags, no error; `gcd docs --root platform/render/testdata/root` still works. Test in Task 2 + Task 3.
5. Pipe `|` or newline in a description/pattern breaks the markdown table → escaped. Test in Task 1.
