# gitops-cd

Capability YAML (`capabilities/`) + team registry (`teams/`) → CUE renderer (`render/`) → generated manifests (`rendered/`), promoted by Kargo, synced by Argo CD, all running locally on kind (`infrastructure/`). Overview and logins: `README.md`. Terms: `GLOSSARY.md`. Decisions: `docs/adr/`.

## Layout
- `capabilities/<cap>/{owners.yml,stages,targets,apps}`: YAML only; folder name = capability name. App owners: `apps/<app>/owners.yml` else capability `owners.yml`.
- `teams/<team>.yml`: githubTeam + idpGroup (Keycloak group); platform-owned.
- `render/`: CUE package `render` (module at repo root, `cue.mod/`): `input` path routing, `clusters` registry, `team` stages/targets + prod autoPromote rule, `owners`, `app` layered merge, `pipeline`, `k8s`, `delivery` Kargo/Argo CD + promote RBAC + AppProjects, `files` outputs + CODEOWNERS fragment. `schemas/` generated editor schemas (committed), `testdata/` + golden, `scripts/`.
- `rendered/`: generated by CI on main; never edit. `bootstrap/`: root Applications syncing `rendered/{argocd,kargo}`.
- `.github/CODEOWNERS`: generated from `.github/CODEOWNERS.tmpl` + owners (never edit).
- `infrastructure/<addon>/`: cluster add-ons managed by Argo CD (`app.yaml`, `values.yaml`, `manifests/`). `cluster/kind.yaml`.

## Commands (`mise tasks` lists all)
- `mise run up` / `down`: fresh kind cluster + infrastructure + bootstrap / delete everything.
- `mise run infra`: (re)apply infrastructure apps in order, git creds, bootstrap. `mise run infra-render [addon…]`: show the inlined Applications.
- `mise run lint [cap…]`: full validation → `file:line:col: message`.
- `mise run render [out]`: render all capabilities + regenerate CODEOWNERS.
- `mise run test`: golden + CODEOWNERS + lint cases (`UPDATE=1` accepts golden).
- `mise run schemas`: regen `render/schemas/` after changing `#App`/`#Stage`/`#Target`/`#Owners`/`#Team`.

## Rules
- **Fully local and reproducible**: `mise run up` must go from nothing to working with no manual steps (after the repo is pushed: `rendered/` syncs from GitHub `main`). After changing cluster, infrastructure or auth, prove it with a clean `mise run up`; `mise run infra` alone doesn't catch bootstrap-order bugs.
- **GitOps-only**: no UI user gets create/edit/delete rights in Kargo or Argo CD. Promote rights come only from the generated `owner-<team>` Kargo roles, and Argo CD visibility only from the generated AppProject `viewer` roles (read-only, Keycloak `groups` claim); never from admin claims or global policies.
- **Pin versions**: tools in `.mise.toml`, charts in `infrastructure/<addon>/app.yaml` `targetRevision`, images by tag or digest (`:latest` is rejected).
- **Idempotent tasks**: every `mise-tasks/*` script must be safe to re-run.
- **Secrets** come from fnox (`.fnox.toml`, macOS keychain); `mise run creds` puts git creds in `kargo-shared-resources` and Argo CD. Nothing secret in git.
- Teams never write CUE (ADR 0006); every option is a YAML field in `#App`/`#Stage`/`#Target`/`#Owners`/`#Team`. User-facing validation messages come from `error("...")` in CUE.
- Watch for field shadowing in CUE (`x: x`); use the `_cap`/`_capStages`/`_capTargets`/`_repoURL` aliases.
- **VCS is jj.** No git mutations, no pushes.

## Changing infrastructure
- Edit `infrastructure/<addon>/`, then `mise run infra`.
- **New addon**: create `infrastructure/<addon>/` from an existing `app.yaml`, add it to the ordered list in `mise-tasks/infra`. Order matters: CRDs, webhooks and the OIDC issuer before their users; `argocd` last.
- **Expose a UI**: Traefik `IngressRoute`, not `Ingress`.
- **New OIDC client**: add it to `infrastructure/keycloak/manifests/kargo-realm.json` as a public client with `pkce.code.challenge.method: S256` (and the `groups` protocol mapper if it needs team membership).

## Gotchas
Read `docs/gotchas.md` before debugging networking (ports, `*.localhost`, DNS), login/OIDC errors, Argo CD health or sync status, or Kargo API/RBAC behaviour. When you fix a new non-obvious failure, add it there.
